# Hi, I'm Yousif 👋

I'm an undergraduate Physics student at the **American University in Cairo (AUC)**, interested in experimental particle physics, scientific computing, and software development.

Most of my research work is connected to the **STAR Collaboration** at Brookhaven National Laboratory, where I work with experimental data, detector reconstruction, and analysis software.

## Research

I'm particularly interested in relativistic heavy-ion collisions and the physics we can extract from large-scale experimental data.

Some of the work I've been involved in:

- **STAR Collaboration:** Working with the STAR software framework and contributing to its development.
- **Neutral pion reconstruction:** Working on mid-rapidity \(\pi^0\) reconstruction using the BEMC and BSMD detectors.
- **Anisotropic flow:** Studying direct photon \(v_2\) in isobaric collisions, with the goal of contributing to a journal publication.
- **Simulation and detector studies:** Working with STAR simulation, embedding, and detector-related software.
